# CardaMove off-chain project

TypeScript + [MeshJS](https://meshjs.dev) project generated by CardaMove from a Move project.

- `src/lib/`: runtime library, a one-to-one port of the Aiken `lib/utils` used by the on-chain code. It is vendored from rosetta-redo: **do not edit it here.**
- `src/modules/module_<address>/<Module>.ts`: generated from the Move modules.
- `src/scripts/<name>.ts`: generated from the Move scripts.
- `src/entrypoints.ts`: generated off-chain entry points, one per Move script.

```sh
npm install
npm run typecheck   # type-check the library, its tests and the generated code
npm test            # library unit tests + Aiken parity fixtures
npm run build       # compile to bin/
```
